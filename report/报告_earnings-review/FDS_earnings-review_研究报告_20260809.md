## 二、本期最重要的 3 个变化

**1. 有机 ASV 加速至 7.1%，连续第 5 个季度加速，创 FY24 Q1 以来最高。**
这是本季度最重要的信号。有机 ASV 增速从 FY25 的 4.1%~4.5% 底部区一路回升：Q1 FY26 5.9% → Q2 FY26 6.7% → Q3 FY26 7.1%，且增长遍布全部分部（美洲 7.2% / EMEA 5.6% / 亚太 10.0%）和全部客户类型（机构买方 6% / 财富 10% / 交易撮合 9% / 市场基础设施 7%）。管理层明确归因：AI 采用（AI 产品客户 ASV 增速比整体高出 50%；AI SKU 贡献当季 ASV 增量的 10%+）与"商业卓越"计划（销售转化率 +15%、赢单率 +27%、企业协议续约年限平均 +30%）。这直接回应了市场最关心的"AI 是否在侵蚀数据商"的问题——目前事实是 AI 在驱动扩张。

**2. GAAP 利润大幅下滑（净利 -14.7%、经营利润 -14.3%、GAAP EPS -9.6%），但全部源于一次性/非经常项目；调整后 EPS 反而 +6.1% 超预期。**
GAAP 与调整口径的剪刀差是本季最大噪音。一次性项目合计拖累经营利润约 $26.7M：重组/遣散费 $19.6M、新 CEO 一次性 make-whole 现金+股权奖励 $4.3M、客户破产计提 $0.8M、并购相关 $1.8M。另外技术投入（AI token 消耗、云托管、网络安全）与按业绩计提的薪酬也在抬升成本率。剔除后调整后经营利润率 34.0%（较上年 -280bp），仍在下半年投入计划的中枢附近。CEO 明确表示对利润率回升"有清晰路径"，且正与全年指引中值看齐。

**3. 商业模式的可见性正在结构性改善：企业协议化 + 消费型定价起步 + 大规模回购。**
本季度续约平均年限延长 30%，大部分续约 ASV 以 3 年以上企业协议形式落地，且"没有以价格折让换年限"；MCP（内容 API 服务器）付费客户已进入 Top 100 客户中的 20%，API 调用量环比增长 13 倍。CFO 首次披露消费型（usage-based）收入已在 ASV 中萌芽（"规模尚小，但将是长期增长的重要驱动"）。同时公司回购大幅加速（9 个月回购 $506M，去年同期 $194M），TTM 资本回报 $776.9M，约占当前市值 7.6%。

## 五、关键问题（电话会 Q&A 精选结论）

见 3.3 表格。本季 Q&A 的实质主题只有一个：**AI 是 FDS 的顺风还是逆风？** 管理层的三条证据链：
1. **AI 采用与 ASV 正相关**：使用 AI 产品的客户 ASV 增速比整体高 50%；AI SKU 贡献 10%+ 增量。
2. **AI 增强定价权而非削弱**：续约年限 +30% 而无价格折让；企业协议"以价值为基础"。
3. **AI 降低自身成本**：编码、数据采集、客户服务三线提效，技术人力 -10%。

空方（高盛/Wells Fargo/BofA 等）的追问集中在：margin 改善是否只是时间错配、token 成本是否有回报、消费型定价何时成规模。管理层承认"消费型收入规模尚小"，这是本季唯一未能量化的软肋。

## 七、结论：这份财报改变了什么？

### 7.1 核心结论

**FDS 2026 财年 Q3 财报：超预期（收入和调整后 EPS 双超一致预期），且最有价值的信息是 ASV 连续第 5 季加速至 7.1%。**

严格说这是一份"结构调整型"的财报：
- **看调整后口径**：收入 +6.4%（超 $4.8M）、调整后 EPS +6.1%（超 $0.08）、ASV 加速——**明显超预期**。
- **看 GAAP 口径**：净利 -14.7%、EPS -9.6%——**低于预期**，但降幅全部由一次性项目（重组 $19.6M、CEO 奖励 $4.3M、客户破产 $0.8M）与主动投入（AI token、云、营销）解释。
- **管理层执行**：新 CEO/CFO 首个完整季度，指引兑现度高、回购大幅加速、信息密度高。内控重大缺陷仍未消除。

**净判断**：这份财报对投资论文的净影响为**中性偏强化**——它把"AI 侵蚀"这个最大的空头逻辑第一次用硬数据反击了（ASV 加速 + AI 正相关），但利润率下滑与内控缺陷让它不构成"全面反转"。
