## 二、本期最重要的 3 个变化（不超过 500 字）

**1. 盈利靠金价、不靠产量：H1FY26 收入 +20%、经营利润 +61%，但黄金产量 -9%、品位 -11%。** 收入增长全部来自实现金价 +40%（US$3,421/oz vs $2,437），黄金销量反而下降 11.2%。地下品位从 6.40 降至 5.72 g/t，管理层归因于第二季度冶金回收率下降（"recoveries have normalised"）、Hidden Valley 地震相关磨机电机故障及氰化物短缺。这是"价格属性"远大于"经营属性"的半年——金价周期（美伊冲突 + 央行购金）是盈利主引擎，与同业 AU/GFI 情形一致。

**2. 股息政策翻倍是本期最大"超预期"：中期股息 530 SA分（+100%），新政策允许最高 50% 净自由现金流回馈股东。** 股息政策从"基础 20% + 上限"改为"基础 30% + 按杠杆水平的 upside 最高 20%"，总派发 R3,383m（US$204m）创纪录，占净自由现金流 43%。这是管理层把创纪录金价现金流转化为股东回报的明确信号——FY26 全年分红（含 8 月终期息）可能进一步走高（FY25 全年仅 R2.4bn，FY26 12 个月已 R4.4bn）。

**3. 资产负债表因收购阶段性转负债、但 Q3 已提前转回净现金：并购 MAC Copper（R17.1bn 现金流出）后净债务 R5,544m（0.18x EBITDA），Q3 即转净现金 R1,326m。** 铜转型进入执行期：CSA（澳）24 个月优化中、Eva Copper（澳）FID 后按 20/40/40 投放 A$2.3–2.6bn 资本、Wafi-Golpu（PNG）SML 谈判持续。管理层以高金价现金流"抄底"中周期铜资产，是在商品高景气期做组合再平衡——方向对，但执行风险（capex 超支、整合、地缘）是未来 24 个月的核心观察点。

## 四、附注中的隐藏信息（H1FY26 中报附注）

- [x] **对冲程序是本期最大"账面拖累"**：已实现对冲亏损 R4,483m（US$258m），因现货均价 R2,122,350/kg 远超 collar cap R1,389,496/kg。期末 552,000 oz rand collar 平均 floor/cap = R1,922,834/R2,169,635 每 kg。**含义：在创纪录金价环境下，HMY 的对冲纪律锁住了约 40% 产量的上行空间——这是一把双刃剑，也是空方论点。** 至 2026-03-31，collar 升至 592,000 oz、floor/cap = R2,037,000/R2,291,000（新 collar 以 floor R2.72m/cap R3.02m 入场，保护已上调）。
- [x] **铜流媒体（streaming）负债为新增大项**：CSA 铜银 stream 负债 R5,445m（R4,923m 非流动 + R522m 流动），H1 确认非现金公允价值损失 R861m（US$50m）。与 Franco-Nevada 的既有 MWS 金 stream 并行——HMY 以"融资换未来产量"的方式收购了 MAC。
- [x] **或有对价（contingent consideration）R3,495m**：MAC 交易的递延对价（R1,882m 非流动 + R1,613m 流动），本期重估亏损 R357m。收购总价值约 **US$1.25bn**。
- [x] **一次性/非经常项目密集**：减值转回 R1,074m（正）、收购相关成本 R1,379m（印花税，负）、streaming 公允价值 R861m（负）——三者在税前基本对冲，但显著影响"盈利质量"解读。
- [x] **实际税率上行**：当期所得税 +86% 至 R3,585m（高盈利引致南非矿业税）；实际税率 ~31%（4,337/14,170）。高金价下税负是 FCF 的实质消耗（与 AU 观察一致）。
- [x] **权利金（royalty）大增 +60% 至 R1,439m**：南非权利金与利润/收入挂钩，高金价自动推高——成本曲线的"隐性上移"。
- [x] **电价 +14%**：南非 Eskom 电价高于通胀上涨；水电煤成本已占现金成本大头，是结构性逆风（公司以 100MW Moab PV 对冲）。
- [x] **劳工成本 +6%**：低于计划的矿业通胀；五年工资协议（至 2029-06）带来劳工成本确定性。
- [x] **存货 +27% 至 R4,856m**：含 Hidden Valley 船期递延与金/铜库存增加；需在 FY26 年报观察是否消化。
- [x] **安全记录**：FY26 至今（至 2026-07-20）至少 **5 起**死亡事故（Q2 Mponeng 1 起、Q3 Moab Khotsong/Target 1 共 2 起、6/19 Moab Khotsong 地震落石 1 起、7/19 TauTona 竖井 1 起）；FY25 下半年曾 10 人遇难。**深井开采的安全风险是贯穿性的、不可消除的尾部风险。**
- [x] **环境修复拨备 R6,775m、Silicosis 索赔**：历史遗留负债，规模可控但长期存在。

## 五、桥接至 FY26 全年（即将发布，2026-08-27）

Q3FY26 更新与 FY26 pre-close 已把全年经营数据基本"剧透"：
- **产量**：全年黄金 1.40–1.50 Moz（连续 11 年达标），CSA 铜 ~18kt（上沿）。
- **价格**：H1 实现 $3,421/oz，Q3 单季 $4,293/oz，Q4（4-6 月）金价区间 ~$4,400–4,650 → **全年实现金价或达 ~$3,900–4,100/oz**（兰特口径 9M 为 R2,020,821/kg）。
- **盈利量级**：9M 黄金+铜收入已 R68,385m；按 Q4 产量 ~350koz + 铜 ~5kt、金价 ~$4,400，全年收入或达 **R92–95bn**（vs FY25 R73.9bn，+25–28%）。9M 基本 EPS 对应 H1 15.63 + H2（更高金价）可能显著更高 → 全年基本 EPS 或达 **R36–42**（卖方一致预期 FY26 非 GAAP EPS **R44.09**，区间 R34.6–52.4）。
- **成本**：9M AISC R1,167,679/kg 在指引内，全年应落在指引中段。
- **资产负债表**：期末净现金确认在即（Q3 已 +R1.3bn，Q4 现金流继续为正）。
- **分红**：中期 530 分 + 终期（8 月宣布）——按 30–50% 派发率与全年净自由现金流 ~R18–22bn 推算，**全年股息或达 R700–900 分/股**（US$0.43–0.56），当前价格对应股息率 ~2.2–2.8%。

## 六、与投资论文的关系

HMY 投资论文三支柱（金价弹性 + 资产组合转型 + 资产负债表）在本期均获数据支撑：
1. **金价弹性**：实现金价 +40% → 经营利润 +61%、EBITDA +39%，弹性兑现（金价每 +$100/oz ≈ 税前 $145m ≈ EPS +$0.14）。
2. **铜转型**：MAC 交割、CSA 并表、Eva FID、新融资（7/28 多币种贷款）——转型从叙事进入执行。
3. **资产负债表**：并购后 0.18x 净债务/EBITDA，Q3 转净现金——财务弹性维持。

**削弱项**：产量连续低于计划（-9%），品位 -11%；对冲压制金价上行敞口；安全记录（5 起死亡）与深井地震风险是长期尾因；金价当前 $4,400 处于 52 周区间（$3,310–$5,586）的中上部，盈利含"周期高点"成分。

**金价周期视角**：H1FY26 实现价 $3,421 vs FY25 $2,620 vs FY24 ~$2,300——两年间金价近翻倍。当前 $4,400 现货处于历史高位区间，但已自高点 $5,586 回落 21%。对纯金矿股，盈利与估值双重取决于金价能否维持 $4,000+，这是本报告投资决策部分的核心分歧点（详见投资研究篇）。

## 七、结论：这份财报改变了什么？

1. **超预期、符合预期、还是低于预期？** —— **符合预期偏小幅超预期（"财务超、运营软"的混合体）**。
   - 超预期项：EBITDA/经营利润强劲（+39%/+61%）、中期股息翻倍至 530 分、股息政策上调至 50%、Q3 提前转净现金。
   - 低于计划项：黄金产量 -9%（管理层明确承认"marginally below plan"）、地下品位 -11%、对冲亏损 R4.5bn 放大。
   - 净判断：盈利数字（金价驱动）创纪录、经营交付（产量/品位）低于计划。**这不是一份靠经营能力超预期的财报，而是一份靠金价周期超预期的财报**——与 AU、GFI 同业模式一致。
2. **对投资论文的影响**：**强化**（金价弹性兑现、铜转型执行、资产负债表与股东回报改善）。风险点（产量、成本、安全、对冲、金价周期位置）是已知弱点的延续而非新事实。
3. **下一个催化剂**：**FY26 全年财报（2026-08-27）**——最终 EPS/股息、FY27 指引（CSA/Eva Copper 产量与资本路径、Wafi-Golpu 更新）、对冲与成本展望；随后是金价走势（Fed 路径、美伊局势、央行购金）。
4. **如果你已持有**：**持有**——估值不高（TTM PE ~12.7x、FY27E 前瞻 PE ~6–7x）、股息政策上行、资产负债表净现金。**加仓**触发点应放在"金价企稳确认 + 8/27 财报兑现全年 EPS 与股息"之后；**减仓**触发点：金价跌破 ~$3,300–3,500（成本曲线支撑）且 AISC 超指引、CSA/Eva 资本超支、南非安全或政策黑天鹅。
