## 二、本期最重要的 3 个变化

**1. 现金流质量跃升 + 上调全年指引（正面，核心变化）**
Q2 经营现金流 $793M（同比+63%）、FCF $761M，均为历史最强Q2，转换率 224%/185%。管理层第三次在全年内上调指引：收入区间下限 +$200M（$18.20-18.40B）、非GAAP EPS下限 +$0.10（$12.20-12.50）、OCF指引 +$50M（约$1.85B）、资本开支下调至约$250M（隐含 FCF 指引上调约$150M）。"在健康业务承压的背景下仍能上调指引"是管理层刻意强调的多元化盈利能力的证据——剔除VBA的其余业务有机收入预期 +7%、调整后EBITDA预期 +19%。

**2. Defense 分部爆发：book-to-bill 2.2x，防务技术进入成长期（正面）**
Defense 分部 Q2 book-to-bill 高达 2.2x（TTM 1.9x），收入 +6.2% 有机加速，非GAAP利润率 9.9%。支撑因素：>$1B 的 DoW 低成本集装箱弹药（LCCM）框架协议（3,000枚/2030年前）、IFPC 进入满产、小型巡航导弹（AGM-190A "Sphere"）飞行测试与实战部署、Golden Dome 追加 18 颗导弹预警/跟踪卫星传感器载荷、Navy 中型无人水面舰艇（USV）潜在量产合同（Q4 有望授标）、BBG(X) 战列舰设计、>$44B/10年 的低成本弹药TAM。CEO披露 Defense 未来12个月可见机会管道达 $12B。防务科技（Defense Tech）成为最清晰的增长引擎。

**3. Health 分部利空确认：VBA 激励金暂停 + 重竞标（负面，但已纳入指引）**
VBA（退伍军人事务部）暂停全行业医疗伤残鉴定（MDE）激励金至2026年底（行政审查所致），Health 收入 -7.6%（第四个供应商全面进场 + 激励金变化），分部利润率 23.4%（同比 -2.4pct）。管理层明确：2026全年影响已完全纳入上调后的指引；国内区域合同预计延期约6个月（至2027年中）、国际/离岗前合同延期1年（至2027年9月）；重竞标草案RFP随时可能发布，正式竞标预计2026年末至2027年初决策。Q4 运行率被管理层定义为 2027 年该业务的"跳板点"。

## 六、与投资论文的关系

LDOS 观察/持仓论文核心变量为：(1) 防务科技（Defense Tech）成长期是否兑现——**本季度强烈强化**（book-to-bill 2.2x、$12B管道、LCCM/IFPC/USV/卫星载荷多点开花）；(2) Health 重竞标风险——**本季度确认利空但已定价并纳入指引**（激励金暂停全行业、重竞标时间表清晰、延期桥梁明确）；(3) 现金流质量——**显著强化**（224%转换率、FCF指引上调$150M）；(4) 估值——12.85x TTM / 11.2x forward，处5年低位。

## 七、结论：这份财报改变了什么？

### 7.1 超/符/低预期判定

**总体：超预期（Beat）**。理由：
1. 非GAAP EPS $3.26 vs Zacks 一致预期 $2.90，**超约12%**；
2. 收入 $4.56B 创纪录，超预期（Zacks/StockStory 均称超预期）；
3. 连续第三个季度上调全年指引；
4. 市场反馈：财报后两日股价 +10.9%。

**但需指出结构性混合**：GAAP 净利润/稀释EPS 同比 -9%/-7%，调整后 EBITDA 利润率 13.8% vs 15.2% 下滑 1.4pct。超预期的实质是"**在利润端承压（VBA+并购整合费用）下，靠现金流转好+防务科技爆发+指引上调**"，并非利润率的全面改善。若只看 GAAP 利润表，是**低于**上年的季度。

### 7.2 对投资论文的影响

| 论文要素 | 影响 |
|---------|------|
| 防务科技增长引擎 | **强化**（book-to-bill 2.2x，$12B管道，弹药/空间/海上下个里程碑） |
| 现金流质量 | **强化**（Q2纪录，FCF指引+$150M） |
| Health/VBA风险 | **确认利空**（激励金暂停），但重竞标结果未出，影响待定 |
| 政府预算/CR风险 | 中性偏负面（9/30前CR概率上升，MD&A明示） |
| 估值 | **强化**（12.85x TTM为5年低位，FCF收益率12.5%） |

### 7.3 下一个催化剂

1. **2026 Q3 财报（约2026年10月底）**：VBA 正式 RFP + 2027 年该业务轮廓 + Defense 加速兑现验证。
2. **Navy 中型无人水面舰艇（USV）量产授标**（管理层暗示Q4决策）。
3. **LCCM 量产就绪审查**（2026年8月底）→ 2027年夏飞行测试 → 全速量产。
4. **SES/Analogic JV 交割**（2026下半年）——去风险化 + 现金回流。
5. **9/30 政府拨款/CR**：政府停摆风险。

### 7.4 操作建议（若已持有）

**持有**。逻辑未破坏、反向强化（现金流+防务科技+指引上调+估值低位），Health 是唯一实质风险且已定价。加仓信号：VBA 正式 RFP 条款优于预期 / USV 量产授标 / 股价回落至 $115-125（bear 情景下沿）。减仓/退出信号：VBA 重竞标明显丢失（国内区域合同）、2027 指引中 Health 利润率跌破 15%、政府预算显著削减。
