## 第二步：生意本质分析——段永平"对的生意"

### 一句话定义
**ABEV 是"巴西的啤酒垄断税"：以 ~65-70% 的巴西啤酒市场份额（公司未披露精确数，第三方估计），用高毛利（51%+）的啤酒 + 高端化 + 数字分销网络，把巴西人的消费习惯转化为稳定现金流，并派发 ~80% 利润给股东。**

### 商业模式画布

| 要素 | 描述 |
|------|------|
| 客户 | 巴西大众消费者（日常/社交场景）+ 酒吧/超市/便利店渠道 + BEES 连接的数百万 B2B 客户（300 万+ 为第三方估计，未逐一验证） |
| 收入性质 | **快消品复购**（啤酒是高频、低客单、习惯性消费；非可选） |
| 毛利结构 | 毛利率 51.4%，啤酒行业全球最高之一（规模 + 寡头定价） |
| 定价权 | 极强：2025 H1 巴西啤酒 NR/hl +6.2%，约超通胀 50% |
| 分销 | 巴西全国性分销网络 + BEES 数字化（同业无法复制） |
| 经营杠杆 | 高（固定分销/制造网络，销量波动直接传导利润率） |
| 护城河来源 | 寡头份额 + 品牌组合 + 规模分销 + 数字生态 |

### 5 年盈利能力趋势
毛利率 49.3%→51.7% 稳步抬升（产品组合高端化 + 成本管控）；经营利润率 22.2%→27.3% 持续扩张；**这是"低速增长 + 高利润转化"的教科书**——即使营收停滞（FY25 -1.4%），经营利润率仍连续 4 年抬升。FCF 利润率 ~27%（TTM），ROIC 25.7%，**是一门"把钱变成更多钱"的生意。**

### 段永平式追问
- **"这门生意好在哪？"** 好在：巴西啤酒寡头（70% 份额的定价权）+ 高毛利 + 高现金流 + 低资本开支 + 分红 80%——**在巴西做啤酒，相当于收"消费税"。**
- **"如果只能用一句话描述？"** 巴西啤酒的"印钞机"，增速平庸但质量顶级，关键风险全在"巴西"两个字上。
- **"如果股市关闭 5 年，你愿意按 $3.00 持有吗？"** 5 年后这家公司大概率还在，还在赚 50% 毛利的钱，还在派 ~80% 的利润。**问题不是生意会不会死，而是美元计价的 5 年回报——若雷亚尔年均贬值 5-8%，即使经营零增长，美元回报也可能为负。** 这是持有 ABEV 的"汇率税"。

## 第三步：护城河评估——巴菲特"经济护城河"

| 护城河类型 | 历史强度 | 当前状态 | 验证 |
|-----------|---------|---------|------|
| **品牌/定价权** | **极强** | **稳定偏宽** | 巴西啤酒 ~65-70% 份额（第三方估计，未验证）；2Q26 巴西啤酒 NR/hl +3.8%（ex-MP +4.4%），H1 +6.2% 超通胀 ~50%；高端（premium 占 25%）定价能力验证 |
| **转换成本** | 低-中 | 稳定 | 啤酒本身无转换成本，但品牌习惯 + 渠道货架 + 冷饮柜锁定形成实际粘性；巴西消费者品牌忠诚度高 |
| **网络效应** | 无 | 无 | 不适用（传统快消） |
| **规模效应** | **极强** | **加强中** | 巴西最大分销网络 + BEES 数字化（B2B 客户数百万级、GMV +58%）+ 规模制造；规模优势随数字化加深 |
| **技术/专利壁垒** | 低 | 低 | 啤酒无专利壁垒；壁垒在品牌 + 分销 + 监管 |

### 护城河趋势
- **过去 5 年（2021-2026）**：整体**维持**——主流啤酒销量下滑被高端化/无醇/数字化的量价补位；NAB（含糖饮料）被健康趋势侵蚀是主要窄化力量。
- **未来 5 年预判**：**宽化概率大于窄化**。(a) 高端化（premium 25%→目标更高）+ 无醇（+30%/年）是全球啤酒最好的结构性组合；(b) BEES/Zé 数字生态加深渠道锁定；(c) NAB 若在 H2 转正则补上短板。**主要威胁：巴西宏观经济长期恶化 + 消费降级（消费者从 premium 退回主流）+ 含糖饮料健康监管。**

### 巴菲特式追问
**"10 年后这条护城河还在吗？什么能摧毁它？"** —— 护城河 10 年后大概率还在（70% 份额 + 品牌 + 分销的寡头格局极难被撼动，过去 30 年证明）。**最可能摧毁它的是"非经济力量"**：巴西政治/税收政策剧变、雷亚尔崩溃、或消费结构代际迁移（年轻人不喝啤酒）。**结论：护城河是 ABEV 最确定的资产，比增长更可靠。**

### 历史类比
- **最相似的历史类比**：**巴西公用事业股 / Petrobras**——"高股息 + 高盈利质量 + 巴西宏观 beta"，长期回报被汇率与政治周期吃掉。买入 ABEV 本质是"买入巴西盈利质量 + 做空雷亚尔"。历史上巴西消费股的美元回报长期被汇率侵蚀。
- **正面类比**：**墨西哥 Modelo / 可口可乐 FMX（Femsa）**——新兴市场饮料寡头，若本币企稳 + 高端化，可长期重估。ABEV 在巴西的地位接近 FMX 在墨西哥。

- **低置信度**：三情景概率分布（35/45/20 为主观判断）、雷亚尔中长期走势、NAB 是否转正、巴西宏观周期位置。

### 投资确定性（基于生意本质）
- **确定的**：ABEV 是一门"巴西啤酒寡头 + 高毛利 + 高现金流 + 高分红"的真生意，10 年后大概率仍在；3.8% 股息 + 10% FCF yield 是真实的现金回报（以雷亚尔计）。
- **不确定的**：**美元计价的回报率**——这取决于雷亚尔走势（20 年累计贬值 70% 的历史）、巴西宏观、以及 NAB/世界杯后的销量节奏。**公开资料无法给出确定答案。**
- **本报告结论（观望）反映的是"汇率与宏观的不确定性"，而非"生意质量差"**：如果只看生意本身，ABEV 是 A+ 级资产；但投资决策需要"价格 + 时间 + 货币"三重确定，当前货币维度不满足。
