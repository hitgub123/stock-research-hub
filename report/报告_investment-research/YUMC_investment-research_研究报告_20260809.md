## 模块二：生意本质分析（段永平 · 对的生意）

**一句话定义**：中国大众化餐饮的分销帝国——以肯德基为现金奶牛、必胜客为增长修复器、塔可钟/咖啡/中餐为期权，靠"门店密度 + 数字化会员 + 自有供应链"三重规模效应构筑壁垒。

### 2.1 商业模式画布

| 要素 | 特征 |
|------|------|
| 收入模式 | 93% 自营门店销售（重资产）+ 7% 加盟费/供应链（轻资产，正向转型） |
| 复购驱动 | 会员体系（2.7 亿活跃会员）+ 高频快餐（工作餐/下午茶/外带）→ 习惯性消费 |
| 数字化 | 外卖占 54%，自有 App/小程序触达，KCOFFEE/KPRO/车购（car-side pickup）新场景 |
| 供应链 | 全国物流中心 + 自有供应链管理 → 食品成本率 31.5% 的规模优势 |
| 品牌矩阵 | KFC（QSR 第一）、Pizza Hut（休闲餐饮第一）、Lavazza/KCOFFEE（咖啡）、塔可钟、小肥羊/黄记煌（中餐） |

### 2.2 盈利能力趋势（5 年）

- **利润率周期**：FY2021 高点 14.1% → FY2022 疫情谷底 6.6% → 连续 9 季扩张至 11.1%（2026 Q2）。**利润率修复周期已走完大半**，剩余扩张空间主要来自必胜客品牌收购（+2.8ppts）与规模杠杆
- **FCF 质量**：5 年经营现金流均 > 净利润（OCF/NI 1.6-1.8x），FCF 从 $442M（FY2021）增至 $940M（TTM），**现金流是这家公司最被低估的品质**
- **资本回报承诺**：2024-2026 三年每年 $1.5B 资本回报（约市值 10%）；2027 年起 ~100% FCF 返还 → **变相提高股东实际回报**

### 2.3 经营杠杆与结构

客单价下降（KFC -3%、必胜客 -11%）+ 同店量升（+5%/+13%）= **以价换量**，靠门店新增 + 同店交易量增长维持收入；利润靠"规模杠杆 + 效率"而非涨价。这是消费降级下的被动选择，**但管理层通过门店扩张（+67% Q2 净开）用规模换利润，是主动对冲**。

**段永平式追问：这门生意好在哪？** 好在"必需品中的最优选"——消费降级时，从正餐降级到快餐（KFC 受益）、从星巴克降级到 KCOFFEE（咖啡受益），YUMC 是**降级受益者**而非受害者；坏在客单价天花板与外卖骑手成本的长期挤压。

## 模块三：护城河评估（巴菲特 · 经济护城河）

| 护城河类型 | 强度 | 证据与推理 |
|-----------|------|-----------|
| **规模效应** | 🟢 强 | 19,297 店（KFC 13,789）覆盖 2,700+ 城市，食品成本率 31.5%，配送中心网络全国化；新进入者无法复制同等密度 |
| **品牌** | 🟢 强（KFC）/ 🟡 中（Pizza Hut） | KFC 中国 QSR 第一 36 年；Pizza Hut 品牌收购后**从"租品牌"变"有品牌"**，边际改善定价与创新自由度 |
| **转换成本** | 🟡 中 | 快餐转换成本低（消费者可随时换麦当劳/华莱士），**但**会员积分、2.7 亿会员数据、App 触达构成行为粘性 |
| **网络效应** | 🟡 弱-中 | 非典型网络效应；但外卖密度→配送效率→更多订单的正循环存在（54% 外卖占比） |
| **特许经营模式** | 🟢 结构性 | 加盟占比 18%（目标新开 40-50%），向轻资产转型；KFC/塔可钟 12 年增长激励协议锁定 |
| **供应链/数字化** | 🟢 强 | 自有供应链管理系统 + 中国最大餐饮会员体系之一；KCOFFEE/KPRO/车购是差异化创新引擎 |

**护城河趋势（5 年视角）**：KFC 护城河**变宽**（外卖占比 45%→54%、会员 2.7 亿、KCOFFEE 300+ 店、KPRO 300+ 店）；Pizza Hut 护城河**从窄到中**（品牌收购 + WOW 下沉 + 汉堡吧创新）；整体护城河**在变宽**，但被"中国消费降级 + 本土对手（华莱士、塔斯汀、瑞幸 9.9 元咖啡、萨莉亚）价格战"部分侵蚀。

**巴菲特式追问：10 年后这条护城河还在吗？什么能摧毁它？**
> 10 年后还在——前提是中国城市化/餐饮连锁化率仍在提升。摧毁它的路径：① 中国消费长期通缩使客单价永续下行；② 本土品牌以极致性价比（如塔斯汀、瑞幸）重塑价格带；③ 外卖平台佣金/补贴规则突变；④ 食品安全黑天鹅；⑤ 中美地缘导致品牌资产风险。

### 4.1 失败路径清单

| 失败路径 | 概率 | 影响 | 触发信号（可监测） |
|---------|------|------|------------------|

| 外卖平台佣金/补贴政策突变 | 中 | 中 | 外卖占销售比 + 利润率双降 |
| Pizza Hut 收购整合失败/过桥贷款再融资风险 | 低-中 | 中 | 2027 年再融资利率大幅上升 |
| 中概/美国审计/地缘脱钩监管风险 | 低-中 | 高 | VIE 政策、PCAOB 变动 |
| 食品安全事件 | 低 | 极高 | 公开报道 |
| 必胜客 800 店/年加速扩张导致单店回报率下滑 | 中 | 中 | 新店 payback >3 年、单店营收下滑 |

### 4.2 历史类比

- **麦当劳中国（金拱门）**：2017 年出售给中信/凯雷后，以更低客单、更快扩张跑赢大盘——证明"中国餐饮规模 + 本地化"模式可行，但资本结构（杠杆）是负担。YUMC 无此杠杆问题。
- **星巴克中国**：2024-2025 年深陷瑞幸 9.9 元价格战，同店连季下滑，估值重估——**这是 YUMC 客单价风险的真实对照组**。
- **3Com（芒格式反面教材）**：技术上"领先"但商业模式被破坏性创新击穿——YUMC 不是技术公司，护城河是运营而非技术，此类比风险低。

### 4.3 空方核心论点（收集）

1. **"中国消费没见底"**：客单价 KFC -3%/必胜客 -11% 是结构性的——消费者在降级，SSS +1% 靠交易量撑，不可持续（空方观点）。
2. **"外卖是利润黑洞"**：54% 外卖占比 + 骑手成本上升，餐厅利润率持平已现端倪，补贴战回归将侵蚀利润。
3. **"Pizza Hut 收购是接盘"**：$1.2B 买一个增长停滞、客单暴跌的品牌 IP（此前中国必胜客系统销售 2024 仅 +3%），许可费节省 19.5x 估值"便宜"但底资产本身在恶化。
4. **"中概估值陷阱"**：任何美国/中国地缘摩擦都会让折价永久化，PE 17x 可能已是"合理"而非"便宜"。
5. **"开店过度激进"**：H1 净开 1,196 家（全年目标 1,900+），在客流疲软时大规模开店会稀释单店收入与回报率。

**芒格式追问：我最可能在哪里犯错？聪明人为什么不买/做空这家公司？**
> 我最可能错在**高估中国消费企稳的速度**——把"以价换量"读成策略而非迫不得已。聪明人不买的核心是"中国风险敞口无法定价"：不是公司不好，是**宏观无法预判 + 汇率/监管不可控**。空头的最大弹药是客单价数据。

| 中国餐饮连锁化率 | 2025 约 20-22%，仍显著低于美国/日本（50%+）→ **长期连锁化红利仍在** |
| YUMC 在价值链位置 | 上游（食品/供应链）→ 中游（品牌+运营+数字化）→ 下游（门店+外卖）。YUMC 拥有中下游全部 + 部分上游（自建物流） |
| 消费分级 | 高端收缩（星巴克）、大众化扩张（KCOFFEE/必胜客 WOW）——YUMC 卡位"大众化升级"的甜点区 |
| 技术路线风险 | 低——餐饮的技术变革（AI 点单、机器人、智能供应链）是**成本优化**而非**模式颠覆**，YUMC 是应用方而非被颠覆方 |
| 客户/供应商集中度 | 供应链分散（无单一依赖），客户为 C 端大众（无集中度风险）✅ |

### 6.2 文明级判断

餐饮不处于"蒸汽机/电力/互联网/AI"级别的范式转移中，但处于**中国消费文明的二次转折**：从"增长叙事"转向"性价比叙事"。这一转折对 YUMC 是**顺风**（大众化品牌受益于降级）但也是**逆风**（客单价承压）。20 年后回看，YUMC 更可能成为"中国大众餐饮时代的标准石油"（规模 + 现金流 + 品牌矩阵的复合体），而非 3Com——前提是中国消费不进入"失去的三十年"。

**李录式追问：站在 20 年后回看，这家公司是"这个时代的标准石油"还是"昙花一现的 3Com"？**
> 更像"标准石油"——但有一个关键前提变量：中国消费升级的中长期路径。若中国 2 亿家庭逐步迈入"吃饱→吃好→吃方便→吃体验"，YUMC 是最大受益者；若陷入长期通缩，它从"标准石油"降级为"公用事业"（低增长、高分红、类债属性）——两者都是可持有的资产，只是回报率不同。
